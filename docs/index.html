操作说明
· 点序号 → 灰线标记「已掌握」（再点取消）
· 点单词 → 音节拆分 ⇄ 原词，并发音（美音）
· 点例句 → 朗读整句（Andrew / Brian 双音色）
· 点词条其他地方 → 发音
· 点页码 → 弹出快速翻页滑块（拖动跟手；松手按趋势翻页、多拖多翻，回拉超过一成页宽则反悔不动；再点或点别处收起）
· 状态池：只背序号范围内的词，划掉即剔除；剩余到阈值后，点「重置」才把范围往后推进（不当场刷新）；可开「池内乱序」
· 设置 / 划线 / 自测解锁 / 上次位置自动保存；每次进入先落主菜单。「开始背诵」原样继续上次的页面，页面内容（哪些词、顺序、遮蔽）只在点「重置」时重建
