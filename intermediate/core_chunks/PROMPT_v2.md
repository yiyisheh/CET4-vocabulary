# 任务：按新释义重写「核心意象」卡（v2）

## 背景

这是一本帮零基础自学者备考四级的单词书。像 take / over 这样的常用多义词，卡片上有一张「核心意象」卡：用**一个具体画面**（image）把几个看似不相干的中文义项串起来，再用一行推导（derive）说明每个义项是怎么从画面里长出来的。

单词的释义刚刚改版：现在只保留**四级真题里实际出现过的义项**，按重要性排好序。旧卡片是按旧的词典式释义写的，可能解释了现在已经删掉的义项，也可能漏了新出现的义项。你的任务是按新的义项表重写每张卡。

还有一条新规则：卡片上的释义行最多只显示前 5 个义项，**其余义项只在核心意象卡里出现**。所以 derive 必须覆盖义项表里的**全部**义项，一个都不能漏，学生才能看到全部义项。

## 输入

`intermediate/core_chunks/v2_in_XX.json`：`[{rank, word, senses, shown_in_def, old}]`
- `senses`：这个词的全部义项，按重要性排序，每条是「词性+中文」，例如 `v.采取（行动、措施、方法），选择；冒（险）（take action / take measures）`。
- `shown_in_def`：释义行显示前几个义项；排在它后面的义项只有你的卡片里会出现。
- `old`：旧卡片 `{image, derive}`，写法照它的风格来。

## 输出

`intermediate/core_chunks/v2_out_XX.json`（XX 与输入相同），一个 JSON 对象，输入里每个词都必须作为键出现，值是以下两种之一：

1. **卡片** `{"image": "...", "derive": "..."}`
2. **不做** `null`：义项表里的义项彼此都很接近、一看就懂，不需要画面来串（例如「健康的；有益健康的」）；或者确实找不到一个真实的核心意义把它们串起来，硬串就成了牵强附会。**宁可 null，不要编。**注意：null 的词，释义行会改为显示全部义项。

## 写法规则

- **image**：一个**具体的动作或空间画面**，不是词典释义的翻版，一般 8–20 个汉字。旧 image 仍然贴切就沿用，不贴切再改。
- **derive**：
  - 先写最贴近画面的基本义，接 ` ⇒ `，再逐个写引申义。每个义项后用全角括号写一句**为什么**（画面怎么变成这个意思），可以附很短的英文搭配（`：run a business`）。
  - **覆盖 senses 里的每一个义项，不多不少**：不写表外的义项（旧卡里有、表里没有的，删掉）；写每个义项时，要原样用上它中文释义里的至少一个词（去掉括号部分，按「，；」切开后的任意一个），例如 `v.采取（行动、措施、方法），选择；冒（险）` 写「采取」或「选择」都可以。校验脚本按这一点检查覆盖。
  - 顺序按道理走，从基本义推到引申义，不必照 senses 的顺序。
  - 词性切换时标出（`n. 轮到（…）`、`adj. 固定的（…）`）。
  - 有义项确实与画面无关（同形异源，或语义早已断开）时，放在最后写「X 单独记」，例如 `n. 罐头 单独记`。不要硬扯。
  - 长度：义项不超过 6 个时，一般不超过 110 个汉字；义项更多时可以放宽，但每个义项的「为什么」要短。
- 学生是零基础，解释要用大白话。
- 全部用中文标点；英文搭配用半角。不要 Markdown，不要换行。
- 以英文母语者语感为准，也可以参考 Longman / Collins / Oxford 的义项结构或可靠的词源。准确优先。

## 交付前自检

运行 `python scripts/core_task.py check v2_XX`，直到输出 OK。它检查：JSON 合法、键集合与输入完全一致、卡片的 image 和 derive 都非空、derive 覆盖了每个义项。

## 回报

用中文简短回报：卡片数和 null 数；null 了哪些词、为什么；最拿不准的 3–5 条及原因。
